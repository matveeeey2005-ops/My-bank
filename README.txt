МОЙ БАНК — PWA

Файлы:
- index.html — приложение (ваш исходный код сохранён)
- manifest.webmanifest — настройки установки PWA
- sw.js — Service Worker и офлайн-кэш
- icons/ — иконки приложения

Публикация:
1. Создайте GitHub-репозиторий (или откройте свой).
2. Загрузите ВСЁ содержимое этой папки, сохранив структуру.
3. В Settings → Pages выберите Deploy from a branch.
4. Выберите ветку main и папку /(root), нажмите Save.
5. Откройте выданную GitHub Pages ссылку по HTTPS.
6. На Android в Chrome: меню ⋮ → Установить приложение (или Добавить на главный экран).
   На iPhone в Safari: Поделиться → На экран «Домой».

Важно:
- Для установки PWA нужен HTTPS; GitHub Pages его предоставляет.
- После первой загрузки приложение кэшируется и основные файлы доступны офлайн.
- Данные и баланс хранятся локально в браузере/на устройстве (localStorage).
- При очистке данных браузера сохранённые данные приложения могут исчезнуть.
- Это демонстрационный виртуальный банк: реальные платежи и банковские операции не выполняются.
